# IELTS Personalized Coaching Engine

## Goal

Upgrade the IELTS Speaking report from one-off question feedback into a personalized coaching system that can identify a candidate's recurring speaking habits and turn them into practical next-step training advice.

## Requirements

- Preserve official IELTS score/report contracts while allowing report structure expansion.
- Build a `learning_profile` for each scored attempt from:
  - current attempt turns and scores
  - current transcript evidence
  - existing training observations / weak-item history
- Use the profile in per-turn AI coaching prompts so advice can refer to recurring habits, not only the current answer.
- Provide deterministic fallback coaching that is still personalized when Codex is unavailable.
- AI coaching and next-step advice must be written in natural Chinese for mainland Chinese IELTS learners. Official IELTS criterion labels may remain English, but explanatory guidance should not be English-first.
- Add a report-level `personalized_coaching` block with:
  - one primary focus
  - recurring habits
  - evidence from transcript / previous weak items
  - a short next-practice plan
- Keep weak-item scheduling internal; do not expose a separate weak-item training page in the report.
- Frontend report detail should render the personalized coaching block clearly without disrupting the original History / Mock / P1 / P2 / P3 navigation.

## Acceptance Criteria

- Every scored attempt includes `learning_profile` and `personalized_coaching`.
- Turn-level `ai_coaching` can use profile context when generated by Codex.
- Fallback turn coaching changes based on detected recurring habits.
- Existing reports without these fields remain viewable.
- Tests cover profile creation, fallback personalization, and scored report payload shape.
- `python -m py_compile web/ielts_server.py tests/test_ielts_web_server.py` passes.
- `python -m unittest tests.test_ielts_web_server` passes.
- `node --check web/static/app.js` passes.
