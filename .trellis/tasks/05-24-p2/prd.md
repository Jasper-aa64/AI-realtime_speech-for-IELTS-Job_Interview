# 调整 P2 串题素材库布局和提示入口

## Goal

修复 P2 串题素材库编辑和练习提示入口的交互：串题素材本身就是原文，不再单独显示原文板块；串题素材和相关 P3 追问通过不同入口打开不同窗口；P2 素材库分类卡片改为每行两个，避免过挤。

## What I already know

* 用户明确要求去掉“原文”板块。
* P2 素材编辑窗口保留“串题素材”和“相关 P3 追问”两个内容区。
* P2 练习中的素材提示入口显示串题素材窗口。
* P3 根据 P2 追问时的黄色提示入口显示相关 P3 追问窗口。
* P2 素材库分类卡片桌面布局应为两列：人物/地点，事件/物品，特殊题目素材单独占一格。

## Requirements

* 删除 P2 素材编辑中的独立“原文”输入区。
* 保存和接口负载不再使用 `original_text`。
* P2 素材弹窗只展示串题素材。
* P3 追问弹窗只展示相关 P3 追问。
* P2 素材库分类列表默认两列布局。
* 不引入数据库迁移；相关 P3 追问继续存 `metadata`，兼容旧库。

## Acceptance Criteria

* [ ] P2 语料库编辑器没有“原文”板块。
* [ ] P2 黄色提示按钮打开串题素材窗口，不显示相关 P3 追问。
* [ ] P3 黄色提示按钮打开相关 P3 追问窗口，不显示串题素材。
* [ ] P2 素材库分类卡片桌面端每行最多两个。
* [ ] `/api/p2-corpus` 不因新增字段导致 500。
* [ ] JS/Python 语法检查通过。

## Out of Scope

* 不重做完整语料库视觉风格。
* 不新增数据库列。
