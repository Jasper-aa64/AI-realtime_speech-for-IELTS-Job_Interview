# Brainstorm Practice and Particle Accent Design

The expanded cue requirements header gains a 30px circular play control before `编辑正文`. Its icon comes from Lucide's official asset and is centered with a fixed grid container. Clicking it opens a same-origin P2 URL carrying the cue ID and an autostart flag, leaving the Brainstorm tab untouched.

The Brainstorm category card gains an absolutely positioned particles.js canvas behind the existing icon and copy. Square particles drift slowly across a bounded right-side strip. The canvas is non-interactive, theme-aware, and motion is disabled when the operating system requests reduced motion.
