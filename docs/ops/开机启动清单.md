# 开机启动清单（IELTS Studio · Windows）

> 一页纸。开机后照抄执行即可。底层细节见 `docs/WINDOWS_STARTUP_AND_PUBLIC_ACCESS.md`。

## 正常情况：不用管

三个服务都是 **Automatic**，开机会自动起来，平时不需要任何操作：

- `ielts-django` — 本地后端 `http://127.0.0.1:8767/`
- `ielts-worker` — AI 报告 worker
- `ielts-cloudflared` — 公网 quick tunnel

公网地址是随机 `*.trycloudflare.com`，**每次 cloudflared 重启会变**。永远以 `get-tunnel-url.ps1` 的输出为准，不要记死某个地址。

## 1. 开机后验证（30 秒）

```powershell
cd C:\Users\liangjunming\Desktop\AI_Project
Get-Service ielts-django,ielts-worker,ielts-cloudflared
Invoke-WebRequest http://127.0.0.1:8767/ -UseBasicParsing | Select-Object StatusCode
.\scripts\windows\get-tunnel-url.ps1
```

期望：

- 三个服务都是 `Running`
- `StatusCode` = `200`
- 最后一行打印**当前可用**的公网地址（拿这个发出去）

## 2. 打不开 / 502 时（照抄）

```powershell
cd C:\Users\liangjunming\Desktop\AI_Project
Restart-Service ielts-django;     Start-Sleep 3
Restart-Service ielts-worker
Restart-Service ielts-cloudflared; Start-Sleep 8
.\scripts\windows\get-tunnel-url.ps1
```

跑完再做一次第 1 步验证。

## 3. 还不行就看日志

```powershell
cd C:\Users\liangjunming\Desktop\AI_Project
Get-Content .runlogs\django.err.log     -Tail 60
Get-Content .runlogs\cloudflared.log    -Tail 40
```

## 4. 极少：重装服务（需要管理员）

只有服务被删 / 改了参数才需要。右键 PowerShell「以管理员身份运行」：

```powershell
cd C:\Users\liangjunming\Desktop\AI_Project
.\scripts\windows\install-services.ps1
```

## 红线

- **不要**用 `start-ielts-stack.ps1` 做长期保活：它退出时会在 `finally` 里把 daphne+worker 一起杀掉，且不重启。它只用于临时手动调试。
- 不要去记某个固定的 `trycloudflare.com` 地址；换了就用第 1 步重新取。
