# IELTS Studio 项目/商业分析会话交接说明

## 背景

当前产品是一个面向国内雅思用户的本地/公网 Web 训练工具，已经覆盖口语、写作、语料库、Takeaway 复习、拼写错词训练、报告和账户余额等模块。最近一次真实用户试用反馈集中在“功能很充实，但新手不知道怎么用”和“局部 UI 信息密度高、按钮语义不够清晰”。

## 用户访谈信号

- 用户认可题库整理价值，尤其是 Task 2 分类题库、Takeaway、写作积累、拼写训练这些能力。
- 用户不熟悉产品时，会不知道按钮入口的含义，例如 Takeaway 需要点击“开始”再按 A/D，拼写训练可按 Enter 继续。
- 用户认为可以补充新手教程、界面引导或视频教程。
- 用户提到如果从辅导业务切入，可以找英语专业、了解雅思的人一起开始，负责辅导和教程视频。
- 用户对 Claude/GPT 计费敏感，建议默认不要乱切 Claude，因为额度可能被题库整理消耗。
- 用户关注公网地址稳定性，方便给老师或外部试用者看。

## 当前产品定位建议

短期更适合定位为：

- “雅思口语/写作 AI 训练工作台”
- “国内雅思考生的题库整理 + 个性化复习 + AI 批改工具”

不建议一开始宣传成完全替代老师。更合理的商业切入是：

- AI 负责高频批改、题库归类、语料积累、复习提醒。
- 老师或英语专业辅导者负责校准内容质量、录教程、做高价值诊断。

## 可商业化模块

1. 题库资产

- 剑雅/机经题库整理、分类、配图、筛选。
- P1/P2/P3 口语题库和保留题/新题。
- Task 1/Task 2 写作题库。

2. AI 批改与报告

- 口语四维评分、中文解释、Band 7 表达改写。
- 写作分段批改、拼写纠错、语法/表达升级。
- 个性化学习画像和后续训练建议。

3. Takeaway / 写作积累

- 用户可保存表达，点击听英文。
- 支持 A/D 记忆曲线复习。
- 适合做成“每日 10 分钟复习”的留存功能。

4. 辅导服务

- 老师查看学生报告，指出最应该改的 1-3 个问题。
- 老师录屏讲解如何用产品准备口语/写作。
- 可做“AI 工具 + 人工点评”的混合服务。

## 当前最大阻力

- 新手上手成本高：功能多，但缺少自然引导。
- 一些按钮需要解释，比如题库助手、Takeaway 开始、A/D、拼写训练 Enter。
- UI 在缩放、不同浏览器、窄屏时还会有局部挤压。
- AI 来源/余额/公网部署这些基础设施概念对普通用户不友好，需要隐藏复杂度。

## 建议优先级

1. 新手引导

- 每个核心模块加 3 步以内的轻引导。
- Takeaway：说明“点击开始 -> 点卡片听英文 -> A=掌握，D=明天再复习”。
- 拼写训练：加明显“继续下一题”按钮，同时保留 Enter 快捷键。

2. 老师/辅导者试用包

- 准备一个示例账号，含完整口语报告、写作报告、Takeaway 复习数据。
- 给老师一份 5 分钟演示流程。
- 重点展示：AI 批改是否像真实教学、题库是否足够可信、学生是否能坚持复习。

3. UI 清理

- 保留高价值功能，但减少“看不懂的按钮”。
- 对高级功能做渐进显示，不要让新手第一眼看到太多工具。

4. 商业实验

- 先找 3-5 个雅思备考用户和 1-2 个老师试用。
- 观察是否愿意每天打开、是否愿意为批改/陪练/老师诊断付费。
- 不急着做支付，先验证“是否真能帮助用户提分和坚持练习”。

## 给下一会话的分析问题

- 这个产品更适合 To C 订阅，还是“老师 + AI 工具”的半人工服务？
- 第一批付费用户应该是考生、老师，还是培训机构？
- 哪些功能必须产品内自解释，哪些适合用视频教程解决？
- 如果只保留 3 个卖点，应该是题库、批改报告、复习系统中的哪几个？
- 如何设计一个 7 天试用路径，让用户明显感觉到价值？
