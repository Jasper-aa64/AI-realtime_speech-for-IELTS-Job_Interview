# SPEC — P2/P3 语料库重构：个人素材库 vs 神奇题库彻底隔离

> 指挥(本会话)定目标/边界/数据模型/验收;**不写生产代码**。实现交 Codex。
> 角色:用户=设计/验收;Codex=实现。本 SPEC 是唯一权威需求来源。
> 背景:当前 P2 库页面把"用户个人素材"和"考季题库"混在一起,编辑题库题卡会污染个人库,P3 练习来源/强度选项也冗余。本 SPEC 重新厘清。

## 0. 一句话目标
把**跨考季的个人串题素材库(A)**和**考季级的神奇题库(B)**在数据存储与 UI 上彻底分开,互不污染;并按新规则收敛 P3 练习的"来源(3 个)"与"强度(2 个)",让"根据神奇题库练"成为默认、类 P1 的一问一答。

## 1. 核心概念:两套语料,彻底隔离

| | **个人库 A** | **神奇题库 B** |
| --- | --- | --- |
| 定位 | 用户级、**跨考季不变**、纯手动准备的可复用素材 | **考季级**官方题(如 2026 may august 56 题) |
| 分类 | 人物 / 地点 / 事件 / 物品 / 特殊题目 | 按考季题目列表 |
| 来源 | 用户「新增」手填 | json 种子(`data/ielts/part2/<season>_topics.json`) |
| 正文 | `material_text`(现有) | **逐题独立存储**,按 `question_id`(见 §2) |
| P3 | 用户为该素材手写的追问(待填/已填) | 题库自带 `p3_follow_ups` + 用户可编辑覆盖 |
| 用途 | 练 P2 时**链接**进报告 band7/辅导;其 P3 作"根据 P2 报告"模式提示 | P2 报告编辑语料 + P3「根据神奇题库」练习 |

**铁律(本次重构的根本):**
- **编辑题库题卡(B)只写进 B 的存储,绝不写进个人库 A。**
- **个人库 A 只接受用户手动「新增/编辑」,永不被题卡操作污染。**
- A 与 B **无"升级/搬运"通道**;个人库是用户自管编辑区。
- A 与考季**完全无关**:换考季,A 原样不变;B 随考季切换。

## 2. 数据模型

### 2.1 个人库 A —— 不动
- `P2CorpusEntry`(现有,`apps/speaking/models.py:149`)保持:5 分类、`material_text`、`metadata`。
- A 的 P3:沿用现状(素材自带、待填/已填),作为"根据 P2 报告"模式提示来源。
- **本次不改 A 的模型/链接进报告的逻辑**(上一轮已接通 prepared_corpus,保持)。

### 2.2 题库 B 正文 —— 新增,按 question_id 存
新增模型(仿 `P1CorpusEntry`,`models.py:127`):
- `P2BankCorpusEntry(UserOwnedModel)`:`user`、`question_id`(**唯一键的一部分,跨考季复用**)、`question`(题面快照)、`corpus_text`(用户正文)、`last_ai_answer`(AI 参考,可空)、`metadata`。
- `UniqueConstraint(user, question_id)`。
- **跨考季复用**:同一 `question_id` 在不同考季重复出现时,展示同一条用户正文(不因换考季丢失)。

### 2.3 题库 B 的 P3 追问 —— 新增,逐条/逐题存
新增模型(仿 P1,挂在 P2 `question_id` 下):
- `P3BankFollowupCorpusEntry(UserOwnedModel)`:`user`、`p2_question_id`、`followup_id`(稳定 id)、`followup_question`(追问题面)、`corpus_text`(用户为该追问准备的语料)、`last_ai_answer`、`metadata`。
- `UniqueConstraint(user, followup_id)`(或 `user, p2_question_id, followup_index`)。
- 初始题面来自题库 json 的 `p3_follow_ups`;**有几条用几条,不强制 5 条**(当前数据 3 条/题)。用户可编辑各条语料。

> 说明:神奇题库本体(56 题 + p3_follow_ups)是**只读种子**,从 json 读;用户的正文/追问语料是上面 B 的可写存储。

## 3. P2 库页面行为(截图那个页面)
1. **个人库 A 区**(5 分类卡片):只展示用户手动新增的素材。**编辑题库题卡不得在此出现新条目。** 修复当前"编辑题卡 → 进个人库"的 bug。
2. **题库 B 区**(按考季列出题卡):每张题卡两个按钮——
   - **「正文」** → 编辑该题的 P2 正文语料(写入 `P2BankCorpusEntry`,§2.2),类 P1 编辑语料弹窗。
   - **「P3 追问」** → **点开弹窗**,列出该题对应的题库 P3 追问条目;每条可**像 P1 一样**点进去编辑语料(写入 `P3BankFollowupCorpusEntry`,§2.3)。
3. 两区视觉/数据来源明确区隔,用户一眼能分清"我的素材"和"考季题库"。

## 4. P3 练习「训练来源」—— 只保留 3 个
当前 4 个(`web/static/index.html:256-259`):按话题练 / 根据 P2 报告 / 根据 P2 素材 / 自定义主题。改为:

1. ❌ **删**「按话题练(`topic`)」。
2. ❌ **删**「根据 P2 素材(`p2_corpus`)」。
3. ✅ **新增并设为默认**「**根据神奇题库**」:选一道 P2 题,**直接照搬该题库卡片上的 P3 追问作为初始问题**;类 P1 的**一问一答**,练题库里的题。条数 = 题库该题实际条数(当前 3),不做 AI 生成、不限 5 条。
4. ✅ **保留**「根据 P2 报告(`p2_report`)」:基于刚才 P2 长回答,**AI 生成 4 题**。
5. ✅ **保留**「自定义主题(`custom`)」:用户输入抽象话题,**AI 结合该主题生成 4 题**。

> 生成数量统一为 **4**(P2 报告 / 自定义);旧 `p3_question_gen.md` 的"exactly 5"相应改为 4(仅影响 AI 生成的两个来源;神奇题库来源不生成)。

## 5. P3 练习「训练强度」—— 只保留 2 个
当前 3 个(`index.html:245-247`):标准练习 / 追问压力 / 专项快练。改为:
1. ✅ **标准练习(`normal`)**:每轮一个主问题。
2. ✅ **追问压力(`high`)**:对**每个回答,AI 根据我的回答再追问**。
3. ❌ **删**「专项快练(`drill`)」。

## 6. P3 报告 + 练习中提示
- **来源 = 根据神奇题库**:报告像 P1 —— 有**对应编辑语料库** + **练习中提示**;数据源 = 该 P2 题的 P3 追问语料(`P3BankFollowupCorpusEntry`,§2.3)。
- **来源 = 根据 P2 报告**:练习中提示用**已链接个人素材 A 里的 P3**(`P2CorpusEntry` 的 P3)。
- **来源 = 自定义主题**:无特定语料提示(AI 生成题,沿用通用 P3 辅导)。

## 7. 不变项 / 红线
- 个人库 A 的模型、5 分类、链接进 P2 报告 band7/辅导的逻辑(上一轮接通)**保持不动**。
- **题库题卡编辑绝不写入个人库 A**(本次核心修复点)。
- A↔B 无搬运通道。
- 题库本体只读(json 种子);用户语料走新模型。
- 复用现有 `UserOwnedModel`/`P1CorpusEntry` 模型与视图/路由风格、`WritingError`/`require_user` 约定,别另起炉灶。
- 加模型必须 `makemigrations` 且 `--check` 干净;不引 CDN、不泄露 key。

- [ ] P3 训练来源只剩 3 个,默认「根据神奇题库」;神奇题库来源照搬题库追问、一问一答、不限 5 条。
- [ ] 「根据 P2 报告」「自定义主题」各 AI 生成 4 题。

## 9. 决策记录(已拍板,勿再翻)
- 题库正文/P3 按 `question_id` 存,**跨考季复用**(非考季绑死)。
- A↔B **无升级通道**;个人库用户自管,题库不动它。
- A 的 P3 = 给个人素材手写的追问,用于"根据 P2 报告"提示。
- P3 来源 3 个(神奇题库默认 / P2 报告 / 自定义);删 按话题练、根据 P2 素材。
- AI 生成题数 = 4(P2 报告 / 自定义);神奇题库不生成、照搬。

## 6b. P3 四个独立对象 + 编辑语料库/提示边界(用户确认)
**必须分清的 4 个不同东西(实现勿混):**
1. 根据神奇题库练习的 **P3 流程**(练习中)。
2. 根据神奇题库的 **P3 报告**(练完出报告)。
3. 从 P2 报告进入的 **P3 流程**(练习中)。
4. 从 P2 报告进入的 **P3 报告**(练完出报告)。

**"编辑语料库"按钮行为(按来源/是否链接素材):**
- **来源 = 从 P2 报告进入,且该次 P2 报告链接过素材**:P3 报告里的"编辑语料库",直接编辑的是**与个人素材卡右侧 P3 按钮相同的数据库位置**(即该 `P2CorpusEntry` 的 P3),同一份语料,不是另建一份。
- **来源 = 从 P2 报告进入,但该次 P2 报告没链接素材**:点"编辑语料库"按钮 → **弹提示**(如"本次 P2 报告没有链接素材"),无编辑入口。
- **来源 = 自定义主题**、以及**任何没有链接题库/素材**的情况:点"编辑语料库"按钮同样**弹提示**(目前逻辑下没有编辑入口),不报错、不静默。
- **来源 = 神奇题库**:有编辑入口,编辑 `P3BankFollowupCorpusEntry`(见 §2.3)。

**练习中提示(黄色提示按钮)缺口:**
- 现在 **P3 练习过程还没有 P1/P2 已具备的"黄色提示按钮"**(练习中查看语料提示)。本次需为 P3 补上,数据源按 §6 的来源规则(神奇题库取 P3 追问语料;P2 报告取已链接素材 A 的 P3;自定义无)。
